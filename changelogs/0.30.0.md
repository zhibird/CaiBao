# v0.30.0 · 记忆小本，记住的事由你决定

把长期记忆从一个开关，变成桌宠内可看见、可修正的资料。用户可以直接管理记忆，也能先把聊天放入草稿，核对后再保存，无需调用生成模型。

## 新增

- 桌宠「记忆小本」：查看当前空间与个人全局卡，分页、来源预览、有效／暂停／过期状态，以及明确的新增、更正、暂停、恢复和删除入口。
- 用户聊天旁的「存到记忆」只打开可编辑草稿；保存时才写入。可关联的来源限定为本账号当前对话，不伪造或跨账号展示原文。
- 单独管理相处方式、长期记忆、近期摘要这三类背景文本。文档可编辑或清空，版本冲突需先核对最新内容；内部近期轮次段不会被编辑器改写。
- 保存结果不明时保留草稿、只读核对，不自动重复写入。切换账号或对话后，旧请求结果不能重新填回记忆面板；登录初始化的迟到响应也不能带回旧聊天及保存入口。
- 说明新对话、记忆卡、背景文本、原聊天和 CLI 原生会话的区别；不把删除一张卡包装成清除了所有记录。

## Agent 记忆闭环

- 桌宠普通闲聊不再触发后台自动整理或额外生成调用。正式会话历史继续保留；长期记忆由用户明确保存或批准记忆工具写入。
- 手工保存与 Agent 批准保存共用记忆写入服务，均生成后续聊天可检索的向量，修复“批准记住后有卡片、无索引”的遗漏。
- 卡片与向量一起提交；索引失败时一并回滚，更正失败保留旧正文、摘要与索引。修改正文会清理未同步更正的旧摘要。
- 记忆读取、关键词工具与小本使用一致的状态、到期和个人全局范围；修复 SQLite 时区比较、全局卡访问，以及遗忘工具的同团队用户隔离。
- 背景资料按来源作为数据块进入提示，当前用户要求与运行约束优先，并限制每部分长度。其他渠道原有自动整理使用同一文件锁原子合并，不覆盖编辑期间的新文本。

## 验证与范围

本机全仓 Python **774 passed、3 skipped**，前端 **31 项测试通过**。实际捕获后续模型输入，验证手工保存、逐次批准保存、更正、暂停、删除、到期、记忆关闭、新对话与不同用户／空间的行为；使用假模型和 CLI，不调用真实 DeepSeek 或订阅额度。覆盖远程向量异常回滚、跨进程文档编辑竞争、未知保存结果及旧账号回调；12 项到期时间场景核对数据库、面板、关键词召回与语义检索。

浏览器在无界面模式核对了手动草稿、来源、纯文本展示、暂停、背景清空、小窗口布局和原生隐藏／退出按钮，另通过6个登录初始化延迟与切换场景；原生应用完成 Swift 编译、plist 与本地签名验证。没有弹出桌宠或改动用户模型配置。

卡片、背景文本和聊天仍分别存储。删除或关闭记忆不抹去旧会话，也不更改已经启动的任务或 CLI 原生历史。管理不需要生成模型；接入远程 embedding 后，创建／更正正文可能使用其网络与额度。默认 mock embedding 仍不能保证真实语义检索。
