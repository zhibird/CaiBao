# v0.28.0 · 彩宝来到 macOS 桌面

把现有 Agent 引擎带入原创薄荷绿小猫桌宠。窗口、角色和朗读作为独立交互层，继续复用身份、会话、工具、知识库与记忆。

## 新增

- `/companion` 伙伴页面：呼吸、眨眼、摇尾巴、摸头、喂食、休息；真实 SSE 事件驱动思考、工具执行、审批、完成、失败与停止状态。
- 原生 AppKit / WKWebView 桌宠：透明置顶、拖动、紧凑／聊天模式、菜单栏、系统语音。窗口提供可见的隐藏／退出按钮与 ⌘W／⌘Q；⌘R 重新连接。
- 伙伴档案、互动和排队任务接口；互动独立持久化且不调用模型，演示模式明确显示。
- API／CLI 显式后端选择，独立于聊天／做事方式；支持已配置 API 模型，以及启用后的 Codex、Claude Code、Pi。目录不读取 CLI 凭证，不假设已登录，不自动回退到其他后端。
- DeepSeek 无密钥配置示例，模型名称参考发布时的官方文档，密钥留在用户本机配置。
- API Agent 的协作式停止：清除待审批，阻止后续输出和工具，迟到结果不会恢复任务。已开始的外部操作仍可能完成；运行中的 CLI／workflow 暂不支持此停止方式。
- 本机 SQLite 启动脚本，生成独立随机登录签名密钥，私有目录存放本地数据。Python、Node 状态和 macOS 构建检查接入 GitHub Actions。

## 修复

- 空工具白名单不再被解释为无限制；聊天模式即使收到模型幻觉工具调用也不会执行。
- 伙伴的每次记忆写入分别审批；模型只需提供标题和内容，可信会话空间在服务端补齐。
- 记忆、文档和历史工具过滤当前用户可访问空间，防止同团队私有数据混用。
- 任务和审批原子认领，避免重复流和重复点击造成二次执行。
- 身份切换清空旧界面，恢复审批时读取实时任务状态，通用历史编辑不能重放伙伴任务。
- 修复流式降级步骤编号，以及旧语音取消回调覆盖新语音状态的问题。

## 验证与范围

本机全仓 Python 测试 **684 passed、3 skipped**，覆盖原有工作台与 QQ 适配器；前端状态、UTF-8 SSE 分片、朗读文本与停止状态 **5 项通过**。原生应用已完成 Swift 编译、plist 与本地签名验证，实际核对过紧凑角色和展开窗口。后续可见退出与快捷键修复只构建验证，遵照用户要求没有重新弹出桌宠。

真实浏览器完成本地测试账号注册、会话恢复、流式演示回复、模型／后端状态和新对话检查。CLI 通过模拟 Pi 子进程验证协议闭环；本次未使用用户 API Key 或订阅额度，不宣称真实模型或 CLI 登录已验活。尚未提供 Apple 公证安装包、全局语音监听或系统应用控制。

启动与模型配置详见 [桌宠使用说明](../docs/companion.md)。
