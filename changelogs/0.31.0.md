# v0.31.0 · 换个大脑，还是同一个彩宝

API、Codex、Claude Code、Pi 共享有界的正式对话。切换后端时补上它尚未见过的交流，接回原生 CLI 时避免重复投递；每个任务单独记录本次选中的执行身份，不拿之后的偏好去猜过去。

## 新增

- 统一正式历史装配器：优先最近完整轮次，默认6轮、24,000字符；省略或截短有说明，当前任务独立保留。非终态投影排除，失败、停止、中断和部分完成记录保留明确状态，旧对话不能变成新的工具授权。
- CLI 续接凭据区分 session 建立、派发中、成功及结果不明。成功且有原生 session 证据后，才推进真正发送过的消息 ID 与本 CLI 成功轮次；不重复补入它自己已经处理的任务和答复。
- 模型、声明连接、运行参数或角色变更时新建原生会话并装入近期正式历史。旧字符串 session、失败、崩溃或不明结果不再被当作精确续接证据；重连不能自动重跑同一任务。
- 运行身份和上下文选择单独持久化。CLI 不再解析或保存 API 默认路由；未配置的 CLI 模型标为自选，不冒充已知模型。公开端点剥除用户信息、查询参数和片段，不保存密钥或原始角色内容。
- 当前任务与历史预览显示「本次执行」及衔接信息，偏好和底部明确表示「下次」。旧任务没有快照时不猜模型；同时修正桌宠聊天区宽度和历史预览滚动可见性。

## 执行一致性

- 所有托管模式共享同一对话执行槽，覆盖 API、CLI 和审批续接。生产同步 Agent 与 App 调用也由同一运行器持有任务，保留原有同步模型协议与等待结果的入口。
- API 等待审批时，模型、连接或凭证配置变化会拒绝续跑，保留原审批且不执行动作；恢复配置后才可继续，不能悄悄换模型使用原授权。
- API 租约过期记录中断并释放会话槽；CLI 仍可能有活子进程，继续保留工作区占位，直到原所有者清理。
- CLI 状态使用私有文件权限、跨进程锁和原子替换；身份及上下文两列提供 Alembic 升降级和旧 SQLite 启动兼容。

## 验证与边界

本机 Python 全仓 **891 passed、3 skipped**；前端 **41 项测试通过**。使用真实服务入口、数据库与假 CLI 子进程验证 API→CLI→API→原 CLI，捕获实际 API 请求与 CLI 标准输入，核对补充、去重、换线、失败恢复及用户／会话隔离。8项实际审批场景覆盖模型、默认／账号连接与密钥变更、恢复原配置和历史快照不变。

会话状态、跨进程竞争、同会话 API／CLI／审批互斥、过期和清理异常、历史预算及迁移也通过检查。后台无界面浏览器验证本次／下次身份、未知模型、旧任务、只读历史和桌宠布局；macOS 应用完成编译、plist 与本地签名验证。上述验证未调用真实模型或改变用户配置。

正式历史不等于长期记忆或 CLI 隐藏上下文；本模块不做生成式压缩，不保证无损恢复原生状态。CaiBao 无法感知 CLI 自己配置目录中的账号／默认模型变化。直接手工创建而未注入运行器的内部服务不具有托管租约保证。更多规则与参考见 [后端连续性说明](../docs/backend-continuity.md)。
