# 彩宝：从本地服务到 macOS 桌宠

彩宝现在是一只原创薄荷绿小猫：会眨眼、摇尾巴、回应摸头，在处理真实任务时切换专注、等待确认和出错的表情。聊天、工具调用、会话和记忆沿用 CaiBao 的 Agent 后端；macOS 原生窗口负责悬浮、拖动、菜单栏和系统朗读。

## 第一次启动

在仓库根目录操作。需要 Python 3.11 或 3.12；原生桌宠另需 macOS 13+ 和 Apple Command Line Tools。首次安装命令行工具可运行 `xcode-select --install`，按系统提示完成后继续。

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
./scripts/run-macos.sh
```

启动器会构建 `build/CaiBao.app`，连接已有的本地服务，或自动启动一个只监听 `127.0.0.1:8000` 的服务。看到彩宝后，展开「聊一会儿」，创建本地账号或使用已有账号登录。无需配置模型也能先看外观和互动；默认 `mock` 是演示回复，不是真实模型推理。

桌面上的「隐藏」或 ⌘W 会收起窗口，「退出」或 ⌘Q 会退出彩宝；菜单栏也提供对应入口。退出会一并停止**此次启动器创建的服务**。启动器复用的已有服务继续运行。构建后的 `.app` 不包含 Python 或后台服务，单独双击它之前，需要先启动本地服务。是否启动悬浮窗口由你决定；不需要桌宠时使用下面的浏览器入口即可。

只用浏览器时，无需安装 Apple 开发工具：

```sh
./scripts/run-local.sh
```

打开 [彩宝网页版](http://127.0.0.1:8000/companion)。同一服务的 [Agent 工作台](http://127.0.0.1:8000/) 保留模型管理、文档、记忆和工具设置。终端中按 Ctrl+C 停止服务。

## 先选执行方式，再选模型

桌宠的「执行后端」明确区分 API 和本机 CLI。选择不会静默改成其他后端；无法使用时会直接说明原因。

| 接入方式 | 当前入口 | 账号与模型由谁管理 |
| --- | --- | --- |
| 自带 API Key | API 模型，默认选项；支持聊天和工具 Agent。 | CaiBao 的 `.env` 或工作台模型配置。 |
| 订阅或本机 CLI | Codex、Claude Code、Pi；仅用于「帮我做事」。 | 相应 CLI 自己的登录、模型和工具权限配置。CLI 是否可用与订阅或 API 授权取决于各工具。 |
| 内置托管网关 | 尚未提供。 | 当前不会创建网关账号、代购额度或静默转发到其他服务。 |

后端列表仅检查服务端是否允许 CLI、相应可执行程序是否存在。它不会启动 CLI、读取 OAuth 凭证、验证登录或查询额度；「可用」不代表已经成功连接上游。切换后端时，API 和 CLI 各自使用自己的模型设置。

## API 模型：DeepSeek 或你选择的兼容服务

默认选择 API 执行方式。仓库提供了 [DeepSeek API 配置示例](../config/deepseek.env.example)，接口为 `https://api.deepseek.com`、模型为官方当前提供的 `deepseek-flash` 别名，密钥留空。模型的实际版本由服务商维护；你也可以按官方控制台选择其他支持工具调用的模型。现有配置不会被示例自动覆盖。

新建或编辑仓库根目录的 `.env`，保留已有的数据库、账号和其他配置，只补齐或修改下面这些项。通用示例中的占位内容需要替换，不要原样使用：

```dotenv
LLM_PROVIDER=openai
LLM_BASE_URL=填写服务商提供的OpenAI兼容接口地址
LLM_API_KEY=填写你自己的API密钥
LLM_MODEL=填写你有权限调用的模型ID
EMBEDDING_PROVIDER=mock
```

这里使用 OpenAI 兼容的 Chat Completions 协议，可接入 DeepSeek、千问等提供兼容接口的服务。按照 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/) 或 [阿里云百炼的 OpenAI 兼容文档](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope) 查找你账号对应的地址和模型 ID；千问的地址还与工作空间、地域有关。填写接口基础地址，不需要手动追加 `/chat/completions`。Agent 模式应选择支持工具调用的模型。

保存后停止并重新启动服务；如果启动器复用了原本运行的服务，也需要重启那一个服务。界面应显示实际模型，而非「演示模式」。模型服务的访问权限、费用和速率限制由你所选的服务商决定。`.env` 中的密钥不要提交到 Git。

`EMBEDDING_PROVIDER=mock` 可以用于初体验，但它不是语义检索模型。需要可靠的语义记忆或文档检索时，再按工作台或现有配置文档接上独立的 embedding 服务。模型配置可以在工作台按账号管理；桌宠的偏好设置中可选择「默认模型」或该账号已配置的 API 模型，当前选择会显示在聊天区并按账号记住。

Ollama 等本地模型可以作为后续适配方向；本次没有提供经过验证的一键 Ollama 配置，也不会自动下载模型。

## 本机 CLI：使用已有的工具与登录

先在服务所在的 Mac 安装你要使用的 CLI，并通过该 CLI 自己提供的流程完成登录及权限设置。CaiBao 不代为登录，也不读取或导出登录令牌。只需安装要使用的一个后端，无需把三个都装上。

在 `.env` 中显式启用，再重启服务：

```dotenv
CLI_AGENT_ENABLED=true
CLI_AGENT_CODEX_PATH=codex
CLI_AGENT_CLAUDE_PATH=claude
CLI_AGENT_PI_PATH=pi
```

服务进程必须能在自己的 PATH 中找到相应命令；也可以在服务端配置完整可执行文件路径。桌宠请求不接受任意路径、权限模式或命令行参数。CLI 模型使用服务端的 `CLI_AGENT_CODEX_MODEL`、`CLI_AGENT_CLAUDE_MODEL`、`CLI_AGENT_PI_MODEL` 配置；留空时由 CLI 自身选择，桌宠不会拿 API 模型名替代它。

选择 CLI 后使用「帮我做事」。这会运行已有的本机 CLI，继续记录任务过程、结果和会话续接，但不注入 CaiBao 的长期记忆、知识库检索或 API 工具。CLI 保有自己的上下文和工具，不受 CaiBao API 工具白名单、逐工具确认或六步预算约束；超时和权限由现有 CLI 配置决定。

CLI 可以访问文件或执行命令，设置工作目录并不等于文件系统沙箱。请在启用前核对相应 CLI 的权限配置，并仅向可信的本地用户开放。更完整的运行参数和权限边界见 [CLI 后端文档](step-13-cli-agent-backends.md)。

## 现在可以怎样相处

| 入口 | 当前行为 |
| --- | --- |
| 摸摸头、小鱼干 | 立即产生轻量互动；登录后按账号保存，不调用大模型。小鱼干是互动，不存在饥饿惩罚。 |
| 歇一会儿 | 进入休息表情；再次点击唤醒。新任务也会让彩宝进入工作状态。 |
| 聊聊天 | API 后端使用模型和会话上下文，不开放工具调用；CLI 不支持此模式。 |
| 帮我做事 · API | 使用有六步工具预算的 Agent 循环；可搜索或读取网页、查询 B 站视频、检索知识库和聊天记录、读取记忆。网络结果取决于网络和所用搜索服务。 |
| 帮我做事 · CLI | 委派所选 CLI，显示其返回的任务过程和结果；使用 CLI 自己的工具、模型和权限。 |
| 回答时参考我的记忆 | API 后端可逐次关闭记忆读取和记忆工具；关闭不会删除过去保存的内容或当前会话记录。CLI 后端不注入这些记忆。 |
| 记忆小本 | 在桌宠内查看、明确保存、更正、暂停和删除个人卡片，管理实际会进入背景的文本；聊天旁的「存到记忆」先打开草稿，再由你保存。普通闲聊不自动整理成长久记忆。 |
| 记忆写入 | API 后端的「帮我做事」可提出保存记忆；需要界面明确确认后才执行。默认不会自动确认。 |
| 任务过程 | 由实际流式事件显示思考、调用工具、等待确认、完成或失败。此处「思考」表示任务正在处理，不展示模型内部思维链。 |
| 停止任务 | API Agent 运行中可请求停止；后续工具不会继续执行，但已开始的外部请求可能仍会完成。正在运行的 CLI 不显示此按钮。 |
| 暂不执行 | 取消待确认任务并清除待确认动作；不会执行这些动作。 |
| 读出彩宝的回复 | 默认关闭。打开后，macOS 壳使用系统朗读；普通浏览器使用其支持的语音合成。停止朗读只停止声音。 |

聊天记录和互动按登录用户隔离。刷新和断线时可从持久事件接回当前任务的文字、工具进度和审批；重连不会重新执行任务，也不会重播旧语音。任务记录可只读查看本次对话的最近任务，状态不明时先核对，再发起新的任务。详细规则见 [可靠任务模块](agent-task-lifecycle.md)。短暂的开心、好奇等反应会逐渐回到自在状态；表情是交互和任务状态的表达，不是对主观感受的判断。

「记忆小本」区分记忆卡、背景文本与原聊天：删除一张卡不等于清除了其他记录，新对话仍会保留同一空间的长期资料。记忆修改会影响后续 API 任务，已有任务不会重跑；CLI 的原生会话仍由 CLI 管理。详见 [记忆小本说明](companion-memory.md)。

原生模式可拖动角色，在展开聊天后输入文字，使用窗口上的隐藏和退出按钮，或通过菜单栏爪印显示、收起、停止说话、打开工作台和退出。窗口是透明悬浮窗，目前不会自行绕屏幕行走。系统语音可用性和声音种类由 macOS 决定；原生桥接和发布说明见 [macOS 桌宠文档](../desktop/macos/README.md)。

## 数据与权限

`run-local.sh` 在没有显式覆盖时，将 SQLite 数据库、上传文件和随机生成的登录签名密钥放在 `data/local/`。已有的环境变量和 `.env` 优先。长期 Markdown 记忆默认在 `data/memory/`；这些本地数据不应作为源码提交。备份或迁移前先停止服务，同时保留数据库和需要的记忆、上传目录。

本地优先指本地窗口、服务和存储：接入远程模型后，发送的消息、相关上下文和所需工具结果仍会交给你配置的服务商。浏览器语音识别的处理方式由浏览器提供商决定，开启前以浏览器的权限提示为准。

API 后端的工具白名单独立于完整工作台，不包含 shell、任意文件访问或 MCP 扩展。可选 CLI 后端拥有自己的工具与权限，不能套用 API 白名单的保证。macOS 原生桥接仅接受本机同源主框架的有限窗口与朗读动作，不执行模型生成的系统命令，也不直接读取模型密钥。

## 当前边界

- 彩宝没有真实意识、情绪或生理需求。原创 SVG 小猫没有使用外部项目的角色模型或美术资产。
- 原生版本不申请麦克风权限，没有全局监听、唤醒词、持续语音对话或原生语音识别。输入时可使用 macOS 系统听写；普通浏览器的语音按钮取决于 `SpeechRecognition` 支持情况。
- 桌宠界面和原生壳没有观察屏幕、操纵其他应用或自行安排后台活动的能力；显式开启的 CLI 后端另有其宿主机权限，不属于桌宠壳的系统控制功能。
- 排队和等待确认的任务可以取消；API Agent 的运行取消通过协作检查生效，已经开始的模型请求或工具调用可能仍会返回。正在运行的 CLI 或工作流不支持此取消，不能承诺强制中止。关闭窗口、切换新对话或停止朗读，都不等于取消任务；断线时先查看状态，避免重复操作。
- 当前提供源码启动和本机构建的 ad-hoc 签名应用；尚无经过 Apple 公证的独立安装包或自动更新。
- 真实智能对话需要你完成模型配置；默认 mock、网络搜索可用性以及设备语音都不能作为真实模型能力的保证。

## 常见问题

**一直显示演示模式。** 检查 `.env` 中的 `LLM_PROVIDER`、接口地址、API Key 和模型 ID，重启正在运行的服务。不要把空密钥或示例模型名当成已配置。

**服务或窗口打不开。** 检查 8000 端口是否已有 CaiBao 服务，查看 `build/service.log`；直接运行 `./scripts/run-local.sh` 可以在终端看到服务错误。脚本复用已有服务时，不会替换它的配置。

**构建提示 SDK 不兼容。** 更新 Apple Command Line Tools；构建器会尝试已安装的兼容 SDK。也可按 macOS 文档用 `CAIBAO_MACOS_SDK_PATH` 指定 SDK。

**没有声音。** 打开偏好设置中的「读出彩宝的回复」，检查系统输出设备和音量。macOS 可在系统设置的朗读相关选项里安装需要的声音；浏览器不支持时使用文字聊天。

**Agent 无法调用工具或搜索失败。** 确认选择「帮我做事」以及支持工具调用的模型，再查看任务过程和工作台。工具调用失败会显示错误，不会被替换成虚构的完成结果。

**CLI 不可选，或启动后报登录错误。** 检查 `CLI_AGENT_ENABLED` 和服务进程 PATH，重启服务后刷新后端列表。列表只检测安装情况；登录、额度和服务商权限需要在 CLI 自己的入口检查。CLI 失败不会自动切换成 API 模型。

## 参考与设计取舍

下面是本轮参考的一手项目。借鉴的是公开产品思路和架构分工，本次没有复制这些项目的代码、角色或美术素材；这些项目具备的其他能力也不代表 CaiBao 已经实现。

| 项目 | 彩宝采纳的设计思路 | 本轮实现范围 |
| --- | --- | --- |
| [AIRI](https://github.com/moeru-ai/airi) | 将可感知的角色、交流方式和模型能力放在同一个陪伴产品中。 | 轻量原创小猫、同一会话中的语音和任务表情；不移植其角色、游戏或实时语音系统。 |
| [goose](https://github.com/aaif-goose/goose) | Agent 的价值来自可扩展工具和实际完成任务。 | 复用 CaiBao 已有 Agent 循环，保留过程、预算和确认；桌宠使用明确的工具白名单。 |
| [Puck for Mac](https://github.com/desFernan/puck-mac) | macOS 桌宠与 Agent 可以共存，系统动作需要独立的授权入口。 | 薄 AppKit 壳、透明窗口、菜单栏和有限同源桥接；尚未实现系统应用控制。 |
| [Open-LLM-VTuber](https://github.com/Open-LLM-VTuber/Open-LLM-VTuber) | 将语音、角色显示和模型适配拆成可替换的部分。 | 设备朗读与状态驱动表情；未引入 Live2D、持续语音识别或完整语音打断流水线。 |

当前分工是：FastAPI 管理身份、会话、模型和工具；Companion 网页展示任务、表情和确认；macOS 壳处理窗口及设备朗读。后续增加语音或角色表现时，可以沿用同一条 Agent 和权限边界。

本轮还参考了用户提供的 shi-xi 项目中关于接入方式分类的高层思路，将 API、CLI 和未来网关明确区分。本仓库的目录、接口和实现由 CaiBao 自行定义，未公开或复制该项目的私有实现、内部文档及资源。

## 回归检查

本地可运行与 CI 对应的检查；测试使用 mock，不需要模型密钥。

```sh
.venv/bin/pip install -r qqbot_adapter/requirements.txt pytest-asyncio
UPLOAD_ROOT_DIR="$PWD/data/test-uploads" .venv/bin/python -m pytest -q
node --test tests/companion-*.test.mjs
./scripts/build-macos.sh
```

最后一步仅适用于 macOS，Node 状态测试不需要安装 npm 依赖。GitHub Actions 会检查 Linux 上的 Python 3.11/3.12 全套测试、前端状态与流解析测试，以及 macOS 原生构建。
