# 换一个“大脑”，接着聊

彩宝将正式对话、API 长期记忆与 CLI 原生会话分别管理。切换 API、Codex、Claude Code、Pi 时，会把当前后端尚未见过的正式交流带过去；接回同一个原生 CLI 会话时，不再重复塞入它已经处理过的轮次。

## 用户能看到什么

偏好设置和底部的「下次」表示下一次请求的选择。当前任务与历史预览中的「本次执行」来自该任务自己的记录，显示后端、已配置的模型和对话衔接方式；不会拿今天的偏好去猜过去用了什么。

CLI 未指定模型时显示「由 CLI 自选」。这是未知的外部选择，不能用 API 默认模型补齐，也不表示已经验证 CLI 登录或额度。旧任务没有运行身份快照时，界面明确说明尚无记录。

同一原生 CLI 会话会显示接回状态和本轮补充的历史数量。更换 CaiBao 声明的模型、运行参数或角色时，会建立新原生会话并重新装入有界正式历史；这与完整恢复原生隐藏上下文是两回事。

## 本轮执行身份

任务获得运行所有权后、实际执行前，确定一份 `execution_identity`：后端、配置选中的模型／提供商、可公开的连接地址及绑定标识。CLI 完全跳过 API 路由，不会因此解析或记录 API 默认模型。

API 身份绑定当轮解析出的模型、连接和凭证配置。等待审批的工具循环续跑前，会重新取得可用凭证并检查绑定；配置变化时拒绝继续、保留当前待确认动作，要求恢复配置或取消后新建任务，不能暗中换一个模型续接已有授权。历史快照不随之后的设置变动而改写。

公开连接地址剥除 URL 用户信息、查询参数和片段。身份和上下文快照不保存密钥、原始角色文本或 CLI 原生 session ID。身份描述 CaiBao 选中的配置；上游别名对应的实际版本及 CLI 自己解析的默认模型不在这里猜测。

## 正式历史如何装配

服务端先校验当前用户和对话，只读取该对话最近最多100条正式记录。API 与 CLI 使用相同装配器，从中保留最近完整轮次，分别受 `LLM_HISTORY_TURNS` 和 `AGENT_CONTEXT_MAX_CHARS` 限制，默认6轮、24,000字符；TOML 对应 `[agent.context] memory_window` 与 `max_chars`。

预算限制的是这部分正式历史，不包含当前任务、角色、检索结果、工具定义或 CLI 自己已有的上下文。当前任务独立追加，不能被历史裁剪掉。正常轮次保持用户／助手配对；只有最新单轮本身超出预算时才明确截短，并优先保留用户要求。省略与截短数量进入 `context_snapshot`。

历史是参考资料，不是新的工具授权。API 在原有消息角色之外增加来源说明；CLI 收到有界、经过转义的引用 JSON。排队、执行中和等待审批的旧投影不作为已完成交流；失败、停止、中断和部分完成的正式记录保留，并明确标记未确认完成，便于下一轮解释或修复。

「不参考我的记忆」关闭长期记忆，仍保留正式会话的上下文。长期记忆、知识库与 API 工具不会因为这次衔接被注入 CLI；CLI 仍使用自己的工具和权限。

## CLI 的投递凭据

工作区中的 `.caibao_cli_sessions.json` 升级为带版本的状态记录。它区分原生会话建立、请求正在投递、明确成功，以及结果不明；只有收到成功结果和原生 session 证据才推进可续接检查点。

检查点记录实际发送过的正式消息 ID，以及该原生会话自己成功执行过的 CaiBao run ID，防止下一次把其自身的答复再当成新增对话。它不依赖时间戳单独判断，因此同一时刻的多条消息不会因游标相同而被跳过。记录有界，消息与 run ID 各保留最多512个；当前装配窗口小于这个范围。

派发前先持久化 `inflight`。失败、崩溃、无法识别的结果或中途关闭不会提前推进历史位置；新任务会重新装入有界正式历史，而不是猜测原任务没有执行并自动重跑。同一个受托管的 run 不会因重连再派发。只有 session 字符串的旧文件不能证明精确续接，会按旧证据重新建立会话。

状态文件使用跨进程锁、原子替换和私有文件权限；原生工作区仍不等于操作系统沙箱。CLI 绑定不包含额外环境变量中的密钥值，密钥轮换本身不会触发重建。CaiBao 无法观察 CLI 在自己配置目录中的登录账号或模型设置是否被外部更改；需要完全独立的一页时，应新建对话。

## 执行互斥与范围

同一用户、团队、对话的托管任务共用执行槽，API、CLI 和审批续接互斥。生产依赖创建的服务将同步 Agent 与 App 调用也送入同一运行器；同步模型协议保留，结果仍由原入口等待返回。不同对话可以并行。

API 失去租约后记为中断并释放会话槽，旧执行不能恢复后续动作。CLI 仍可能有存活的子进程，因此保留工作区占位，直到原所有者完成清理；永久失去原进程时可以新建对话。手工创建、未注入运行器的独立内部服务不具有托管租约保证。

这里没有生成式历史压缩，也不宣称可以无损恢复 CLI 隐藏状态。长对话只携带有限近期原文，完整记录仍在原会话历史中。没有新增后台模型调用、登录探测、自动窗口或自动语音。
