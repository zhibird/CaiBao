# 彩宝的任务计划卡

处理有多个实质步骤的事情时，彩宝可以显示一份简短的工作计划。当前任务、重新连接和只读历史查看同一份记录；普通聊天和一次查询可以直接回答，界面不会要求每次先列清单。

卡片明确标注「模型报告的计划」。进行中、待处理、模型标记完成和取消只表示模型如何安排这轮工作。任务结束、工具报错、用户停止时，系统保留最后报告，不自动补勾步骤。即使全部勾选，也不会改变任务终态、播放完成语音或代替执行回执。

## API 大脑

「一起做事」显式启用本轮控制工具 `update_plan`。它接收完整列表，可附一句公开调整说明：

```json
{
  "plan": [
    {"step": "核对已有资料", "status": "completed"},
    {"step": "整理有来源的建议", "status": "in_progress"}
  ],
  "explanation": "资料已返回，继续整理建议。"
}
```

每次最多10项、每项160字，状态限 `pending/in_progress/completed/cancelled`，最多一项进行中，说明最多300字。空列表表示模型清空计划。接口不接受模型指定用户、会话、任务 ID 或来源，不执行步骤里的文字；也不解析自然语言回复来制造进度。

每轮最多8次计划更新尝试，无效参数和重复快照也消耗额度；相同内容不制造新的公开版本。计划更新不扣外部工具预算，也不计为工具成功或失败。外部动作额度耗尽后，剩余计划额度仍可用于收尾；没有额度时保留原计划。API 工具循环最多15次模型调用，包含最后一次禁用工具的总结，不能靠反复规划无限循环。前置检索中的模型调用与底层网络重试不在此计数内，这不是整个任务的费用硬上限。

审批保存外部动作账本、模型请求次数、原始请求批次和计划尝试次数。确认只继续原任务，不重置任何额度；新格式检查点丢失计数、批次与次数不符时拒绝执行。同一请求的并行调用共用批次，不会误当成多次模型请求，私有批次标记也不会发给模型。旧审批只能从已保存的工具调用记录保守恢复，不能凭空扩充次数。聊天模式的空工具白名单继续不开放计划工具。

## CLI 大脑

计划展示采用 CLI 已经返回的明确结构，不改动它的权限、启动参数或模型配置：

- Codex 的 `todo_list` 事件只有每项文字和完成布尔值；false 展示待处理，不推断进行中。整个列表的 `item.completed` 表示事件生命周期结束，不会把仍为 false 的步骤勾完。
- Claude Code 投影 `TaskCreate/TaskUpdate` 与旧 `TodoWrite`，只接受能以调用 ID 和成功结果配对的结构。新建任务必须取得真实结果 ID，更新还要校验结构化成功、匹配 ID 和确实更新的字段；原生 ID 只用于内部关联。只维护本次执行实际观察到的新建任务，不从原会话补猜未知任务；失败、缺少真实 ID、歧义或无法验证的结果保留原计划。不同版本和模型可能不提供任务工具，界面不保证每轮都有计划。
- Pi 核心事件没有默认计划协议，本模块不从自然语言或未经配置的扩展里猜计划。没有记录时不显示计划卡。

每个运行单独保存，CLI 恢复同一会话也不会继承上轮计划。CLI 展示最多接收64份不同快照；再发生变化时保留第64份并明确标注停止更新，不能把过期计划当最新进展。这个展示上限不改变原生 CLI 的执行预算。

## 保存、恢复和界面

`task_plan_json` 独立保存版本、固定来源、简短步骤与公开说明。写入要求任务仍在运行、所有者一致、旧快照仍匹配；取消、中断或结束后的迟到更新不能改写记录。`plan.updated` 事件用于实时刷新，查询快照用于恢复；相同运行的旧版本、错来源事件和终态后的重放不能降级当前卡片。查询与历史受原有用户权限限制。

计划采用纯文本呈现，不渲染模型提供的 HTML，不保存或展示内部思维。卡片可折叠，小窗口同时打开计划、执行回执和历史时，输入区与隐藏／退出入口仍须可达。查看历史不会再次执行、更新计划或重播朗读。

升级运行数据库会添加可空列，旧任务保留「没有计划」的事实，不从旧回复推测补写。此模块不配置 DeepSeek 密钥、不启用麦克风、不启动桌宠窗口。
